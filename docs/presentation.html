Gap Analysis

Why Commercial Solutions Fall Short

Existing forensic offerings create severe operational bottlenecks for national defense and intelligence agencies.

1. Layer Disconnection

Traditional tools (Chainalysis, Elliptic) operate purely on ledger state, completely blind to P2P network gossip metadata (IP, port, propagation latency). Network NIDS monitor packets without UTXO semantics.

2. Black-Box Opacity

Commercial ML outputs arbitrary risk scores (e.g., "Risk: 88%") without evidentiary breakdowns. Such outputs fail evidentiary standards in judicial courts and executive intelligence briefings.

3. Cloud Dependency

Commercial forensic tools require constant internet uplinks and cloud SaaS backends. They cannot be deployed in classified, sovereign, or air-gapped forensic laboratories.

Storage & Validation Layer

Embedded OLAP with DuckDB

High-throughput analytical storage running entirely in-process without server daemons or network socket overhead.

Why DuckDB Over PostgreSQL/Neo4j?
  • Vectorized SIMD Execution: Evaluates analytical queries 10x-50x faster than traditional row-oriented SQLite or Postgres.
  • Zero Daemon Footprint: Operates in-process via a single file (`chaintrace.duckdb`). Zero background ports or root permissions required.
  • Native Dynamic Array Types: Directly supports multi-input and multi-output arrays (`VARCHAR[]`, `DOUBLE[]`), natively modeling Bitcoin UTXOs.
Multi-Format Ingestion & Fallback
  • Universal Parser: Python generators streaming CSV, JSON, and XML lines without loading full files into memory.
  • Strict Pydantic v2 Validation: Enforces SHA-256 hash regexes, satoshi bounds, port ranges, and valid timestamp formatting.
  • Offline GeoIP Reader: Uses local `GeoLite2-City.mmdb` with deterministic fallback logic for air-gapped systems.

Graph Forensics

Heterogeneous Entity Graph & CIOH

Constructing a unified tripartite graph linking network observations directly to ledger UTXO state.

Graph Topology $G = (V, E)$
  • Nodes $V$: Wallets (addresses), Transactions (TXIDs), and Network IPs.
  • Edges $E$:
    • $IP \xrightarrow{\text{observed\_tx}} TX$ (broadcast origin)
    • $Wallet \xrightarrow{\text{input}} TX$ (funding flow)
    • $TX \xrightarrow{\text{output}} Wallet$ (disbursement)
    • $Wallet_A \xleftrightarrow{\text{co\_input}} Wallet_B$ (common control)
Common Input Ownership Heuristic (CIOH)

Forensic Rule: To execute a multi-input transaction, the private keys for all input UTXOs must be signed simultaneously. Therefore, all input addresses belong to the same entity.

For TX with Inputs [W1, W2, W3]:
⟹ Add Edge (W1 ↔ W2) [co_input]
⟹ Add Edge (W2 ↔ W3) [co_input]
⟹ Add Edge (W1 ↔ W3) [co_input]
Entity Resolution

Unmasking Syndicates via Louvain Clustering

Collapsing thousands of pseudonymous addresses into discrete criminal clusters through modularity optimization.

Modularity Optimization Formula

The algorithm maximizes the density of internal cluster co-spending edges relative to random chance:

$$Q = \frac{1}{2m} \sum_{i,j} \left[ A_{ij} - \frac{k_i k_j}{2m} \right] \delta(c_i, c_j)$$

Automatically converges in $O(N \log N)$ time, identifying multi-wallet clusters without requiring pre-set cluster count hyperparameters.

Two-Phase Iteration Workflow
  • Phase 1 (Local Moves): Evaluates modularity gain $\Delta Q$ of moving node $i$ to neighbor community $C$. Moves node to maximize $\Delta Q$.
  • Phase 2 (Community Aggregation): Compresses detected communities into super-nodes, creating super-edges weighted by cumulative inter-cluster transaction volume.
  • Outcome: In our 1,000-tx test dataset, 2,826 individual addresses were consolidated into 880 distinct clusters in < 1 second.

Machine Learning Engine

Unsupervised Anomaly Detection via Autoencoder

Supervised models fail on novel criminal laundering. Our PyTorch Autoencoder detects zero-day anomalies through an informational bottleneck.

Network Architecture
Input Vector [13 Dim] │ ▼ Encoder 1: Linear(13 -> 32) + BatchNorm + ReLU │ ▼ Encoder 2: Linear(32 -> 16) + BatchNorm + ReLU │ ▼ Bottleneck: Linear(16 -> 8) [Latent Space] │ ▼ Decoder 1: Linear(8 -> 16) + BatchNorm + ReLU │ ▼ Decoder 2: Linear(16 -> 32) + BatchNorm + ReLU │ ▼ Output Reconstructed Vector [13 Dim]
Reconstruction Loss & Calibrated Scoring
  • Reconstruction Error: $$\mathcal{L}(x, \hat{x}) = \frac{1}{D} \sum_{j=1}^D (x_j - \hat{x}_j)^2$$
  • The Bottleneck Effect: Normal retail patterns compress easily through the 8-dim bottleneck. Outlier behavior (velocity spikes, peel chains) produces huge reconstruction errors.
  • Empirical Threshold $\tau$: Calibrated at the 95th percentile of baseline errors.
  • Normalized Anomaly Score: Scaled 0 to 100 for intuitive analyst triage.
Graph Representation Learning

Node2Vec Macro-Structural Embeddings

Capturing structural graph position and multi-hop neighborhood context in dense 64-dimensional vectors.

Biased 2nd-Order Random Walks

Walk transitions are governed by return parameter $p$ and in-out parameter $q$:

  • $p = 1.0$ (Return): Controls likelihood of immediately revisiting the previous node (local clustering).
  • $q = 1.0$ (In-Out): Controls exploration outward vs remaining local (macro-role discovery).
  • Skip-Gram Training: Maximizes log probability of predicting context neighbors within a window of 10 steps.
Air-Gapped Resilient Fallback
  • PyTorch Geometric (PyG): High-speed GPU-accelerated C++ random walk execution when libraries are present.
  • Structural Hash Fallback: Seamless fallback to topological degree, neighbor density, and hash projections if compiled C++ binaries are missing on bare-metal air-gapped targets.
  • Output: Serialized `node2vec_embeddings.npz` enabling instant similarity retrieval across millions of nodes.
Explainable AI (XAI)

Court-Admissible Evidentiary Attribution

Replacing black-box opacity with game-theoretic Shapley value decomposition on every alert.

The Shapley Value Formula

Quantifies the exact marginal contribution $\phi_i$ of feature $i$ across all possible feature subsets $S$:

$$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(|N|-|S|-1)!}{|N|!} \left[ v(S \cup \{i\}) - v(S) \right]$$
  • Efficiency: Sum of contributions equals total reconstruction error difference.
  • Symmetry & Additivity: Guaranteed unbiased attribution.
